# Aponti Academy - Projeto Vagrant & Jenkins

Aplicação prática das ferramentas: **Vagrant** (automação de máquinas virtuais) e **Node.js** (aplicação de servidor).

## Objetivos

- Criar duas máquinas virtuais (VM):
    - **Host:** ubuntu server configurado com Jenkins e Node.js
    - **Prod:** ubuntu server configurado com Node.js

- Provisionar Jenkins e Node.js a partir de um script
