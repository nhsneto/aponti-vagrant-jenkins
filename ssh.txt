
##### SSH #####

1. Criar as chaves na máquina host:
vagrant@host:~$ ssh-keygen -t ed25519 -C "prod"

2. Criar o caminho para o uso de ssh pelo jenkins (precisa de permissão):
vagrant@host:~$ sudo mkdir -p /var/lib/jenkins/.ssh

3. Adicionar a chave pública no arquivo /var/lib/jenkins/.ssh/known_hosts:
vagrant@host:~$ sudo ssh-keyscan -H 192.168.33.10 | sudo tee -a /var/lib/jenkins/.ssh/known_hosts > /dev/null

4. Copiar a chave pública do host:
vagrant@host:~$ cat .ssh/id_ed25519.pub

5. Colar a chave pública do host em authorized_keys na máquina prod:
vagrant@prod:~$ nano .ssh/authorized_keys
