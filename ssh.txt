##### SSH #####

1. Criar as chaves na máquina host:
vagrant@host:~$ ssh-keygen -t ed25519 -C "prod"

2. Copiar a chave pública do host:
vagrant@host:~$ cat .ssh/id_ed25519.pub

3. Colar a chave pública do host em authorized_keys na máquina prod:
vagrant@prod:~$ nano .ssh/authorized_keys

4. Criar o caminho para o uso de ssh pelo jenkins:
vagrant@host:~$ sudo mkdir -p /var/lib/jenkins/.ssh

5. Adicionar a chave pública da máquina prod no arquivo /var/lib/jenkins/.ssh/known_hosts:
vagrant@host:~$ sudo ssh-keyscan -H 192.168.33.20 | sudo tee -a /var/lib/jenkins/.ssh/known_hosts > /dev/null

6. Abrir o jenkins da máquina host na máquina física:
No browser, acessar o jenkins em 192.168.33.10:8080
Selecionar o "ssh agent" plugin para instalação

7. Adicionar a chave privada no jenkins para poder se comunicar com a máquina prod:
Jenkins > Gerenciar Jenkins > Credentials > SSH Username with private Key
Colocar o id da chave: deploy (um exemplo apenas)
Colar a chave privada da máquina host: colar o conteúdo de ~/.ssh/id_ed25519
